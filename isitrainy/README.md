# 오늘 진짜 비옴?

현재 위치 또는 선택한 도시의 오늘·내일 강수 예보를 세 수치예보 모델로 비교하는 정적 웹 페이지입니다. 실제 관측이나 강수 레이더를 보여주는 서비스는 아닙니다. 기상청 예보는 이후 연동 대상으로 남겨 둡니다.

## 실행

저장소 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행하고 `/isitrainy/`을 엽니다. ES 모듈을 사용하므로 `file://` 대신 HTTP로 실행하세요. 외부 공개 시 위치 조회를 위해 HTTPS가 필요합니다. GitHub Pages의 HTTPS에서도 브라우저 위치 기능을 사용할 수 있습니다.

## 위치와 개인정보

- 초기 접속 시 위치 권한을 요청하거나 예보 API를 호출하지 않습니다.
- ‘현재 위치로 확인’을 클릭할 때만 `navigator.geolocation.getCurrentPosition`을 호출합니다. 브라우저가 GPS, Wi-Fi 등으로 제공한 좌표와 오차 범위를 사용합니다. GPS 하드웨어 사용을 보장하지 않습니다.
- 권한 거부, 시간 초과, 미지원 브라우저에서는 도시 검색 또는 서울·부산·제주 빠른 선택을 이용할 수 있습니다.
- 도시 검색은 Open-Meteo Geocoding으로 제공합니다. 기본 검색 범위는 **대한민국**이며 해외 지역은 **전 세계**로 전환해 찾습니다. 국내 검색은 API 국가 필터와 응답 국가 코드 검증을 함께 적용하고, 결과가 없다고 다른 나라로 자동 전환하지 않습니다.
- 제공처의 한글 별칭 누락을 보완하기 위해 `천안`과 `천안시`, `부산`과 `부산광역시` 등 공식 행정구역 이름도 조회합니다. 좌표를 하드코딩하지 않습니다. `충청남도 천안시`, `충남 천안`처럼 공백으로 행정구역을 지정할 수도 있습니다.
- 여러 검색 응답을 중복 제거한 뒤 행정도시 여부·입력명 일치·인구 순으로 정렬하고 최대 10개를 표시합니다. 결과에는 국가·시도·시군구를 함께 표시하며, 사용자가 직접 지역을 선택해야 예보를 조회합니다. GPS에 대한 역지오코딩은 하지 않으므로 도시 이름을 추측하지 않고 ‘현재 위치’로 표시합니다.
- 좌표는 Open-Meteo 예보 요청에 전송합니다. 이 페이지는 좌표·조회 결과를 로컬 저장소, 쿠키 또는 서버에 저장하지 않습니다. 현재 탭의 메모리에만 보관하며, 데이터 제공처의 요청 처리는 해당 제공처의 정책을 따릅니다.

## 예보 비교

Open-Meteo Forecast API를 통해 `ecmwf_ifs025`, `gfs_seamless`, `icon_seamless`를 각각 요청합니다. 매개변수는 `temperature_2m`, `precipitation`, `precipitation_probability`, `timezone=auto`, `timeformat=unixtime`, `forecast_days=3`입니다. 사흘을 요청하는 이유는 내일 마지막 구간(23:00–다음 날 00:00)의 직전 한 시간 강수량까지 포함하기 위해서입니다. 화면은 선택한 위치의 현지 시간으로 남은 오늘·내일만 표시합니다.

- 강수량은 비·소나기·눈의 물 환산량을 포함합니다. 각 API 시각의 **직전 한 시간** 누적량을 해당 구간으로 표시합니다. 현재 시간이 포함된 첫 구간은 한 시간 전체 예보이며 남은 분량만의 강수량이 아닙니다.
- 시간별 강수량 0.1mm 이상을 그 모델의 강수 예측으로 분류합니다.
- 조회 가능한 모델이 두 개 미만인 구간은 비교 부족입니다. 모델 간 의견이 반반이면 엇갈림으로 처리합니다. 누락·오류·`null`을 0으로 바꾸지 않습니다.
- ‘3개 중 2개’는 모델의 예측 일치 정도이며 실제 강수확률 67%를 뜻하지 않습니다. 모델들의 오류는 서로 연관될 수 있습니다.
- 강수확률은 각 모델이 제공하는 값의 최솟값–최댓값과 자료 개수를 표시합니다. 확률을 단순 평균하거나 하루 전체의 보정된 확률로 표시하지 않습니다.
- 우산 안내: 선택한 기간 중 한 시간이라도 과반수 모델이 강수를 예상하거나 개별 모델의 강수확률이 60% 이상이면 우산 권고. 일부 모델만 강수를 예상하거나 개별 확률이 30% 이상이면 예측 엇갈림. 자료가 부족한 구간은 맑음으로 판단하지 않습니다. 이 규칙은 실용적인 안내이며 관측 자료로 정확도나 보정을 검증한 알고리즘이 아닙니다.
- 모델별 업데이트 시각을 API 조회 시각과 혼동하지 않도록 ‘조회’ 시각을 표시합니다. 제공처의 `generationtime_ms`는 예보 발행 시각으로 사용하지 않습니다.

각 모델 요청 실패를 독립적으로 처리합니다. 모든 모델이 실패하면 비 없음으로 표시하지 않습니다. 같은 위치의 갱신 실패 때만 이전 조회 결과를 명확한 안내와 함께 표시합니다. 다른 위치를 조회하다 실패했을 때 이전 위치의 결과를 새 지역 결과로 보여주지 않습니다. 15분 이상 지난 자료에는 이전 조회 자료라고 표시하며, 탭이 보이는 상태에서 15분 간격으로 갱신을 시도합니다. 연속 실패 시에도 매 분 재요청하지 않습니다.

## 외부 연결과 사용 조건

필요한 API 도메인:

- `api.open-meteo.com`: 세 모델 예보
- `geocoding-api.open-meteo.com`: 도시 검색

네트워크가 제한된 개발 환경에서는 두 도메인에 대한 HTTPS 접근이 필요합니다. 초기 개발 중의 프록시 차단이 해제된 뒤, **2026-10-24에 Chromium에서 서울의 세 모델 실시간 응답, 도시 검색·선택, 정상 TLS·CORS 연결을 확인했습니다.** 모든 지역의 데이터 가용성, 실제 기기 위치 정확도 또는 예보 정확도를 보증하는 검증은 아닙니다. 저장소 회귀 테스트는 재현성을 위해 명시적인 모의 응답을 사용하며, 제품은 실제 API를 요청합니다. 실제 날씨처럼 보이는 고정 데이터를 제품에 넣지 않습니다.

Open-Meteo의 무료 공개 API는 비상업용 조건입니다. 광고를 포함한 상업적 운영 전에는 제공처의 최신 이용 조건과 요금제를 확인해야 합니다. 유료 인증키가 필요한 운영으로 바뀌면 정적 JavaScript에 키를 넣지 말고 서버 프록시 등 별도 구성을 검토해야 합니다. 개발용 프로토타입에는 API 키를 넣지 않습니다.

[Open-Meteo](https://open-meteo.com/)의 자료와 지명 데이터에 대해 페이지 하단에 출처·[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)·비교 및 요약 사실을 표시합니다.

## 검증

저장소 루트에서 실행합니다. 브라우저 의존성은 [tests/README.md](../tests/README.md)를 참고하세요.

```sh
node --test tests/rain-forecast.test.mjs tests/rain-geocoding.test.mjs
python3 tests/rain_browser.py
```

Node 테스트는 시간 구간 정렬, 모델 일치·불일치, 확률 범위, 자료 누락, 오래된 예보, 날짜 경계 등을 검증합니다. 브라우저 테스트는 버튼을 누르기 전 무요청, 모의 위치 권한 허용·거부, 지역 검색, 부분·전체 실패, 갱신 실패, 텍스트 렌더링 및 모바일 화면을 검증합니다. 실제 기기의 위치 정확도와 실제 기상 예측 정확도를 검증한 테스트는 아닙니다.
