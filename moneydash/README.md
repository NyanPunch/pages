# MoneyDash

수입과 지출을 기록하고 월별 흐름을 살펴보는 개인용 가계부입니다. HTML, CSS, JavaScript만 사용하며 서버·계정·외부 차트 라이브러리가 필요하지 않습니다. 홈 갤러리에는 아직 연결하지 않습니다.

## 실행

저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `/moneydash/` 경로를 엽니다. GitHub Pages 같은 정적 호스팅에도 그대로 배포할 수 있습니다. `file://` 직접 실행보다 HTTP 실행을 권장합니다.

## 기능

- 수입·지출 기록, 수정, 삭제
- 선택한 달 또는 전체 기간의 수입·지출·잔액 확인
- 카테고리별 지출 비중과 최근 6개월 수입·지출 그래프
- 거래 유형 필터, 내용·카테고리 검색
- 카테고리 추가·삭제: 사용 중인 카테고리와 유형별 마지막 카테고리는 삭제하지 않음
- JSON 백업·복원, 복원 취소 및 잘못된 파일 검증
- 모바일 화면과 키보드로 조작할 수 있는 입력 대화상자

‘기간 잔액’은 선택한 기간의 수입에서 지출을 뺀 값입니다. 실제 은행 계좌 잔액이나 기간 이전의 이월금은 포함하지 않습니다. ‘전체 기간’ 그래프는 현재 달까지 최근 6개월을 보여줍니다. 금액은 양의 정수 원 단위이며 한 내역은 최대 1조 원, 거래 내역은 최대 10,000건입니다.

## 저장과 기존 데이터 이전

데이터는 현재 사이트의 브라우저 `localStorage`에 `moneydash:v1` 키로 저장됩니다. 서버 동기화나 암호화 기능은 없습니다. 동일한 사이트의 스크립트는 저장소에 접근할 수 있으므로, 중요한 기록은 별도로 백업하세요. 사이트 주소·브라우저·기기를 바꾸거나 브라우저 데이터를 삭제하면 기록이 자동으로 옮겨지지 않습니다.

이전 버전의 `transactions`, `customCategories`를 처음 실행할 때 검증하고 가져옵니다. 기존 키는 삭제하거나 덮어쓰지 않습니다. 이전에 삭제한 카테고리를 사용하는 기록이 있으면 해당 카테고리를 복원합니다. 새 저장 형식이 이미 있으면 이전 데이터를 다시 가져오지 않습니다. 서로 다른 탭에서 편집할 때는 저장 직전 변경 여부를 확인하고, 저장소 변경 이벤트로 다른 탭을 갱신합니다.

저장 데이터가 손상됐거나 저장소에 접근할 수 없으면 편집을 중단하고 안내합니다. ‘백업’으로 원본 보관용 파일을 받을 수 있습니다. 원본 보관용 파일은 정상 가계부 백업과 구분되며 직접 복원할 수 없습니다.

## 백업과 복원

‘백업’은 현재 검색·월 필터와 관계없이 **전체 기록과 카테고리**를 내보냅니다. ‘복원’은 `format: moneydash-backup`, `version: 1`인 10MB 이하 JSON 파일을 검증한 뒤, 사용자 확인 후 전체 가계부를 교체합니다. 날짜·금액·중복 ID·카테고리가 잘못된 파일은 반영하지 않습니다.

복원 전 원본은 `moneydash:before-restore`에 추가 보관합니다. 이 키는 가장 최근 복원 직전 데이터만 담으며, 파일 백업을 대신하지 않습니다. 거래 설명과 카테고리는 HTML로 해석하지 않고 텍스트로 표시합니다.
