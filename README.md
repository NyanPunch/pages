# 🗂️ Pages 프로젝트 위키

생활에 유용한 웹 도구를 모은 정적 사이트입니다. 각 프로젝트는 독립된 HTML·CSS·JavaScript로 동작하며, 루트 `index.html`에서 공개된 프로젝트로 이동할 수 있습니다.

## 프로젝트

### 🎰 [복권 번호 생성기](./showmethemoney/)

- 로또 6/45와 연금복권 720+ 번호를 생성합니다. 로또에 포함할 번호와 연금복권 생성 방식을 지정할 수 있습니다.
- 최근 발표된 회차의 추첨일·1등 번호를 표시하며, 로또 보너스 번호와 출처도 안내합니다.
- 공개 데이터 조회가 실패하거나 새 회차 반영이 늦어지면 상태를 구분해 표시합니다.
- 당첨번호 카드와 생성 영역의 스타일을 통일했습니다.
- [사용 방법·데이터 출처](./showmethemoney/README.md)

### 📊 [연금저축 적립식 배분 계산기](./howtodistribute/)

- 총액과 종목별 비중으로 배분 금액·매수 주수를 계산합니다.
- 비중 합계가 100%가 아니어도 비례 배분하며, 입력 정보는 브라우저에 저장됩니다.
- [사용 방법](./howtodistribute/README.md)

### ☔ [오늘 진짜 비옴? — Is It Rainy](./isitrainy/) · 베타

- 버튼을 눌러 현재 위치를 허용하거나 도시를 선택해 오늘·내일 예보를 조회합니다. 위치를 허용하지 않아도 도시 검색·빠른 지역 선택을 이용할 수 있습니다.
- ECMWF IFS·NOAA GFS·DWD ICON의 시간별 강수량, 개별 모델 강수확률의 범위, 예측 일치·불일치를 비교합니다.
- 모델의 합의 비율을 실제 강수확률로 바꾸지 않으며, 자료 누락을 맑음으로 처리하지 않습니다.
- 기상청 예보·실시간 관측·강수 레이더는 아직 포함하지 않습니다.
- 모의 응답·위치 테스트와 실제 API를 통한 서울의 세 모델 예보·도시 검색을 확인했습니다. 실제 기기의 위치 정확도와 기상 예측 정확도는 별도 검증이 필요합니다.
- [비교 기준·위치 처리·API 사용 조건](./isitrainy/README.md)

### 💰 [MoneyDash](./moneydash/)

- 수입·지출 기록, 수정·삭제, 기간 잔액, 월별 분석, 검색, 카테고리 관리, JSON 백업·복원을 지원합니다.
- 기존 데이터의 원본을 보존하며 새 저장 형식으로 이전합니다. 데이터는 브라우저에 저장하며 서버 동기화는 제공하지 않습니다.
- 루트 홈 갤러리에는 아직 연결하지 않았습니다.
- [사용 방법·저장과 복원](./moneydash/README.md)

### 🗺️ 세계 여행지도 · 준비 중

여행한 나라·지역을 표시하는 지도 페이지를 구상 중입니다.

## 로컬 실행

별도 패키지 설치나 빌드 없이 저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 서버를 열고 홈 갤러리의 도구를 선택하세요. 날씨 페이지의 ES 모듈과 홈 패치노트 로딩을 위해 `file://` 대신 HTTP로 실행해야 합니다. 외부 공개 시 현재 위치 기능에는 HTTPS가 필요합니다. GitHub Pages의 HTTPS에서도 동작하도록 구성했습니다.
