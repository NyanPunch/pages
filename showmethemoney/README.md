## **반자동 복권 번호 생성기 ✨**

### **🚀 주요 기능**

  * **로또 6/45**: 원하는 개수만큼 로또 번호 세트를 한 번에 생성할 수 있습니다.
  * **연금복권 720+**:
      * **한 세트만**: 1개의 무작위 연금복권 번호를 생성합니다.
      * **모든 조(각기 다른 번호)**: 1조부터 5조까지 각각 다른 6자리 번호를 생성합니다.
      * **모든 조(동일한 번호)**: 1조부터 5조까지 모두 동일한 6자리 번호를 생성합니다.

-----

### **🎲 사용 방법**

1.  **로또**: 생성하고 싶은 세트 수를 입력하고 **'번호 생성'** 버튼을 누르세요.
2.  **연금복권**: 원하는 생성 옵션을 선택한 후 **'번호 생성'** 버튼을 누르세요.

-----

### **👨‍💻 개발 정보**

이 프로젝트는 다음과 같은 기술로 만들어졌습니다.

  * **HTML**: 웹페이지의 구조를 만듭니다.
  * **CSS**: 디자인과 레이아웃을 담당합니다.
  * **JavaScript**: 번호 생성 로직을 구현합니다.
    

## 지난 회차 당첨번호

페이지 상단에서 가장 최근에 발표된 로또 6/45와 연금복권 720+의 회차·추첨일·1등 번호를 확인할 수 있습니다. 로또는 보너스 번호도 별도로 표시합니다. 연금복권 번호는 앞자리 0을 유지합니다.

- 데이터: [nostra-data](https://github.com/nostra-team/nostra-data)의 공개 `snapshot.json`을 GitHub Raw에서 가져옵니다. 이 출처는 동행복권 공식 API가 아닌 공개 데이터 미러입니다.
- 브라우저에서 직접 요청하며 CORS를 지원합니다. 서버나 API 키는 필요하지 않습니다.
- 페이지를 열 때, 새로고침 버튼을 누를 때, 5분 이상 지난 뒤 탭으로 돌아올 때 갱신합니다. 실제 새 데이터의 제공 시점은 출처의 갱신에 따릅니다.
- 회차와 추첨일의 일치, 번호 범위·중복·자릿수를 검증합니다. 두 복권은 각각 검증하므로 한쪽 응답이 잘못되어도 다른 쪽은 표시합니다.
- 확인한 결과는 `showmethemoney:draw-results:v1`에 저장합니다. 네트워크 오류 시 이전 번호임을 명시하고, 저장된 번호도 없으면 실패 안내와 공식 사이트 링크를 표시합니다. 저장소를 사용할 수 없어도 실시간 조회와 번호 생성은 동작합니다.
- 한국 시간 토요일 22시(로또), 목요일 21시(연금복권)를 지난 뒤 이전 회차만 있으면 새 회차가 반영되지 않았다는 안내를 표시합니다. 이 시간은 추첨 시각이 아닌 갱신 지연 판단 기준입니다.

실제 당첨 여부는 반드시 [동행복권](https://www.dhlottery.co.kr/)에서 최종 확인하세요. 공개 출처의 지연·오류가 있을 수 있으며, 번호 생성 결과는 당첨을 보장하지 않습니다.

브라우저 회귀 테스트는 [tests/README.md](../tests/README.md)를 참고하세요.
